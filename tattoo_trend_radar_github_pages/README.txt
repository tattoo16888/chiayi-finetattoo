# 嘉義微刺青 Trend Radar

這是一個可直接上傳 GitHub Pages 的刺青靈感搜尋網站。

## 上傳方式
1. 打開你的 GitHub repository。
2. 點 Add file → Upload files。
3. 上傳這些檔案：
   - index.html
   - style.css
   - script.js
   - manifest.json
   - sw.js
4. 到 Settings → Pages。
5. Source 選 Deploy from a branch。
6. Branch 選 main / root。
7. 儲存後等一下，就會產生網站網址。

## 手機加入主畫面
iPhone 用 Safari 開啟網站 → 分享 → 加入主畫面。
